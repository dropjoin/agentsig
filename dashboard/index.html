How the demo runs

1. Agent reads the policy from NEAR. 2. A task inside the caps and allowlist passes; an over-cap task is rejected locally before any signature is requested. 3. For a passing task the agent asks the NEAR MPC network to sign a BSC transaction. 4. The action is written back to the policy contract as an audit record.
